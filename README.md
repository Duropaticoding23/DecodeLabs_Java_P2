# 🚀 DecodeLabs: Java Programming - Project 2
## Student Grade Calculator

A robust command-line Java application developed as part of the DecodeLabs Industrial Training / Internship program. This project focuses on core data processing, logic implementation, defensive programming, and precise arithmetic operations.


### ✨ Features
* **Dynamic Subject Handling:** Allows users to input any number of subjects dynamically.
* **Defensive Programming:** Validates user input bounds ($0$ to $100$) to prevent erroneous or malicious data entries.
* **Precision Arithmetic:** Uses explicit type casting to avoid integer division truncation artifacts when computing average percentages.
* **Structured Logic Ladder:** Evaluates percentages tier-by-tier to accurately assign letter grades (`A`, `B`, `C`, `D`, `F`).
* **Professional CLI Report Card:** Formats float outputs to two decimal places for a clean, user-friendly presentation.



### 🛠️ Tech Stack
* **Language:** Java
* **Environment:** VS Code / Terminal
* **Key Concepts:** `Scanner` buffer management, `for`/`while` loops, conditional branching (`if-else`), type casting.
